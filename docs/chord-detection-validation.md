# 多音检测：实现与验证状态

当前状态：本机试用。已接入实时输入及判题；尚无真实吉他录音或声卡演奏的准确率验证，不宣称达到稳定版本验收。

## 方法

- 单音练习、琶音沿用 YIN 与起音门控。和弦走独立链路，不累计单音结果。
- 分析在串行后台队列运行。音频降采样到约 12–15 kHz，使用 4096 点 Hann 窗及 1024 点步进。FFT 使用 Apple Accelerate [vDSP DFT](https://developer.apple.com/documentation/accelerate/vdsp_dft_zop_createsetup)。
- 不把题目音高作为检测器输入：先估计频谱峰值，按低频到高频归并泛音，得到实际 MIDI 集合，再与题目比较。保留八度，不只比较音级集合。
- 静音、削波、噪声或谱峰解释度不足不输出有效判定。弱基音可能无法识别；八度叠音与泛音可能无法分离。这些是当前方法的明确限制。
- 同一音高集合持续至少 450 ms 才输出一次事件，这长于整个分析窗，以避免窗口内短暂先后出现的三个分离单音被当成和弦。
- 止音门控使用最近一个步进的电平，不使用长 FFT 窗的拖尾。持续音不会重复提交；重新弹奏前要止音。
- 输入不录制、不上传。测试波形由程序生成，不使用用户的学习记录或音频。

## 自动化覆盖

- 25 个根音／音区 × 七种类别及适用的闭合排列，共 375 个合成三音组合。
- 不同音量配比、±20 cents 整体偏移、泛音、静音、白噪声。
- 缺音、错误三音、错误八度、额外非目标音不得与目标集合相等。
- 44.1、48、96 kHz 分块输入；同时拨响、短扫弦、止音后重弹。
- 分离的三个单音（每音 120、250、600 ms）不得触发和弦事件。
- 琶音错误顺序不跳过当前音；三音才计一题；重复结束不重复保存；提示、跳过和旧单音统计分离。
- 学习／练习、正常与最大字号、深浅色布局快照。

合成测试不能代表真实吉他的拨弦包络、拾音器频响、泛音强弱、调弦偏差或房间串音。

## 稳定发布前尚需完成

记录真实设备与输入通道、采样率、干净音色设置、各类别及音区样本数量，以及正确组合、错音、缺音、额外音、单音分离演奏的判定结果。统计误通过率、误拒绝率和从拨弦到反馈的延迟。尤其需要验证弱根音、相邻音、音量悬殊与八度叠音。当前真实样本数为 0，这些数值尚未测得。
